# Ember Foundry — Хранители леса

**Построй фабрику. Удержи ночную осаду.** Ember Foundry — фабрика и tower defense в лесу на Godot 4. Днём рубишь лес,
прокладываешь ленты и ставишь мастерские; ночью по дороге к замку идут скелеты, и всё, что ты построил, работает на
оборону. Бесплатная ранняя версия для Windows и macOS.

<p align="center"><img src="assets/video/hero-poster.jpg" alt="Ночной бой у замка" width="100%"></p>

## Игра

- **Фабрика.** Лесорубы, каменоломни, шахты, лесопилки, плавильни, угольные печи и кузницы — 28 производственных и
  транспортных построек. Ленты рисуются мышью; развилки, слияния, перекрёстки и подземные ленты разводят потоки. Залежи
  кончаются, и фабрика переезжает.
- **Оборона.** 11 башен и 22 ветки улучшений: от самострела и катапульты до цепного гарпуна, катушки Теслы и кузнечного
  молота. Башни набирают опыт, из ворот замка выходит отряд — ополчение, лучники, рыцари.
- **Экспедиция.** Процедурные карты под туманом войны. Маяки и разведка открывают сундуки, алтари с кристаллами и
  вражескую крепость. Регион выигрывается победой над боссом шестой ночи или штурмом крепости. Три региона: Изумрудная
  чаща, Янтарная долина, Сумрачные холмы.
- **Прокачка.** Монеты за экспедиции идут в атлас из 119 талантов; 6 достижений, 5 слотов сохранения, испытания после
  победы и контентные моды.

## Как сделано

Шесть недель от первого прототипа (15 сентября 2026) до 0.9.36.

- **Godot 4.7**, рендер Forward+ (Vulkan, Metal), около 25 000 строк GDScript.
- **Графика из кода:** здания собираются скриптами Blender на Python (10 000+ строк), цвет запекается в вершины; в сборке
  368 моделей.
- **Ночной облик:** освещение, LUT-цветокоррекция, GPU-частицы и туман войны, настроенные по референсам.
- **Звук:** 545 звуковых файлов, собранных скриптом из лицензированных записей.
- **Качество:** 138 автотестов, замеры плавности кадров на реальных сохранениях игроков.
- **Выпуск:** одна команда собирает установщик Windows (Inno Setup) и образ macOS (на Windows через WSL), затем
  проверяет в песочнице установку, первый запуск и удаление Windows-версии и прогоняет игровой пакет для Mac.

## Этот репозиторий

Сайт игры (GitHub Pages) и её выпуски. Исходный код игры закрыт.

- `index.html`, `assets/` — статичный сайт без сборки и зависимостей: чистый JS для переключения RU/EN, искр, слайдера
  «день/ночь», тумана войны, лайтбокса и кнопок скачивания под систему посетителя.
- `release.json` — текущая сборка: версия, файлы, размеры, SHA-256; из него читают кнопки скачивания.
- `tools/build_assets.py` — делает из кадров и клипов игры AVIF/WebP/JPEG, H.264 и подмножества WOFF2, рисует превью
  для ссылок.
- `tools/release.py` — публикует сборку: релиз на GitHub с обоими установщиками и свежий `release.json`.
